## Current Features
- Access google and youtube
- Toggle sidebar
- Add new shortcuts

## Language and Framework
- electronjs - used for creating app window and managing external processes
- HTML/CSS/JS - rendering app frontend and user interactions

## Prerequisites
- **Node.js**: `v18.0.0` or higher (Recommended: LTS version)
- **npm** (comes with Node)
- **Git** (to clone the repository)

## Installation and setup
```bash
# 1. Clone the repository
git clone https://github.com

# 2. Enter the project folder
cd Desktop_Organiser

# 3. Install node dependencies
npm install

# 4. Install electron
npm install electron

# 5. Run the Electron application
npm start
```
